# Hari 03 - CSS

Folder ini berisi latihan pengembangan halaman web dengan CSS. Materinya mencakup pengaturan tampilan halaman, tata letak, komponen, tabel, dan formulir pendaftaran.

## Isi Folder

```text
hari_03_css/
├── profil.html       # Halaman profil dan galeri
├── jadwal.html       # Jadwal kegiatan diklat
├── daftar.html       # Formulir pendaftaran
├── css/
│   ├── style1.css    # Gaya halaman profil dan jadwal
│   └── style2.css    # Gaya halaman formulir
├── img/              # Foto dan gambar untuk halaman
└── blog/
    └── artikel_1.html
```

## Materi yang Dipraktikkan

- Menghubungkan file CSS eksternal ke halaman HTML.
- Mengatur warna, tipografi, jarak, dan tata letak.
- Membuat komponen halaman seperti navigasi, kartu, tabel, dan formulir.
- Menggunakan elemen HTML semantik dan gambar.

## Cara Menjalankan

1. Buka folder `hari_03_css`.
2. Buka `profil.html`, `jadwal.html`, atau `daftar.html` di browser.
3. Pastikan folder `css` dan `img` tetap berada di lokasi yang sama agar gaya dan gambar dapat dimuat.

Halaman dapat dibuka langsung di browser dan tidak memerlukan proses build.
