# Proyek 1: Landing Page

Proyek ini merupakan latihan membuat landing page sederhana menggunakan HTML. Proyek berada di dalam materi **Hari 02 - HTML** dan menjadi bagian dari proses belajar dasar pengembangan web.

## Tujuan

- Mengenal struktur dasar dokumen HTML.
- Berlatih membagi halaman menjadi beberapa bagian yang jelas.
- Menyiapkan halaman utama dan halaman profil untuk dikembangkan lebih lanjut.

## Struktur Folder

```text
proyek-1-landing-page/
├── index.html   # Halaman utama
├── profil.html  # Halaman profil
└── readme.md    # Dokumentasi proyek
```

## Cara Menjalankan

1. Buka folder proyek ini.
2. Buka `index.html` menggunakan browser.
3. Buka `profil.html` untuk melihat halaman profil.

Proyek ini belum menggunakan proses build atau dependensi tambahan.

## Pengembangan Selanjutnya

Isi halaman HTML dan tambahkan CSS agar landing page memiliki konten, navigasi, serta tampilan yang sesuai dengan kebutuhan.
