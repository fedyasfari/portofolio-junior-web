Belajar Membuat Website

Ini adalah artikel pertama saya dalam pembelajaran pengembangan web.

Perbandingan XAMPP vs Laragon: Keunggulan dan Kelemahan XAMPP dan Laragon merupakan perangkat lunak untuk membuat server lokal (localhost), sehingga kita dapat membuat, menjalankan, dan menguji website di komputer tanpa harus membeli hosting atau menggunakan internet. Keduanya cocok untuk belajar pemrograman web, khususnya PHP dan database. Keunggulan dan kelemahan XAMPP Keunggulan XAMPP 1. Mudah dipelajari oleh pemula yang baru mengenal PHP dan MySQL/MariaDB. 2. Gratis dan dapat digunakan untuk pembelajaran maupun pengembangan. 3. Menyediakan Apache, PHP, MariaDB, dan phpMyAdmin dalam satu paket. 4. Mendukung Windows, Linux, dan macOS. 5. Banyak tutorial pembelajaran yang menggunakan XAMPP. 6. Memudahkan pengenalan cara kerja web server dan database. Kelemahan XAMPP 1. Mengganti versi PHP tidak sepraktis Laragon. 2. Pembuatan domain lokal khusus memerlukan konfigurasi tambahan. 3. Pengembangan proyek Laravel modern membutuhkan penyiapan tambahan. 4. Dapat mengalami konflik port, misalnya port 80 atau 443 digunakan aplikasi lain. 5. Pengelolaan banyak proyek dengan konfigurasi berbeda cenderung kurang fleksibel.

Saya juga mulai memahami penggunaan path relatif untuk mengakses file pada folder yang berbeda.
