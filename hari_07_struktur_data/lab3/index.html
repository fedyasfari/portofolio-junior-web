HARI 7 · STRUKTUR DATA DAN ALGORITMA

Lab 3 — Pencarian dan Pengurutan

Uji langsung pencarian linear, pencarian biner, Bubble Sort, Merge Sort, dan Insertion Sort.

1. Masukkan data Anda

Contoh: 8, 3, 5, 1, 5. Kosongkan kolom untuk mencoba array kosong.

2. Cari angka

Pencarian biner otomatis menggunakan versi data yang telah diurutkan menaik.

3. Bandingkan penghitung perbandingan (1.000 elemen)

Data acak, terurut, dan terbalik. Perhitungan hanya mencatat perbandingan nilai antar-elemen, bukan waktu.

4. Benchmark 10.000 dan 100.000 elemen

Jalankan benchmark besar lewat terminal VS Code agar browser tidak macet. Buka terminal pada folder ini lalu ketik:

npm run benchmark

Untuk mencoba 10.000 elemen dahulu: npm run benchmark:cepat.

Batas aman 15 detik per algoritma: jika Bubble Sort belum selesai, tabel menandainya secara jujur sebagai melampaui batas, bukan mengarang waktu. Untuk mencoba tanpa batas: npm run benchmark:penuh (bisa sangat lama). Hasil akan tersimpan otomatis dalam hasil-benchmark.csv dan hasil-benchmark.md.
