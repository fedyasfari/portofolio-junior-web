# Proyek 2 — Kalkulator dan Form Validator (versi latihan Lab 5)

Berisi contoh bersih berdasarkan spesifikasi Proyek 2 sebelumnya: ES Module, `textContent`, Grid 4 kolom, penghitungan angka dan validasi form. **Bukan salinan otomatis seluruh source asli pengguna.**

Buka `kalkulator/index.html` dan `validator/index.html` menggunakan ekstensi Live Server pada VS Code, bukan `file://`.

Kalkulator menggunakan `operasi.js` dan `app.js`; validator menggunakan `aturan.js` dan `app.js`. Terdapat tes unit Node.js di `../test/proyek2.test.mjs`.
